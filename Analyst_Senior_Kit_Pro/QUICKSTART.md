# QUICKSTART — Analyst Senior Kit Pro

1) Abra no VS Code → instale as extensões recomendadas.
2) `Ctrl+Shift+P` → **Tasks: Run Task** → **Setup: venv + deps**
3) Configure seu `.env` (copie de `.env.example`).
4) Rodar: **Run: pipeline** ou `scripts/run`.
5) Testar: **Test: pytest**.
6) (Opcional) Dev Containers → **Reopen in Container** para ambiente idêntico em qualquer máquina.
7) Suba esta pasta no Google Drive. O `venv/` pode ser recriado em cada notebook.
